Take notes while your teacher talks

  1. Type the class name at the top.
  2. Click Start listening and allow the microphone. Put your device where it can hear the teacher.
  3. The transcript appears here. Every few minutes Claude fixes words the microphone misheard and turns it into notes on the right.
  4. Press ★ Important when the teacher says something you must remember, like a test topic.

Space start/pause · M important · N update notes · C classes · S settings

Recorded the class on your phone? Upload a recording below, or drop it here.

Ask your teacher before recording a class. Speech is turned into text on this device by the Whisper speech model (a one-time download), so no audio leaves your computer and none is saved. Only the text is sent to Claude to make notes.

Checking for the helper…

  1. Install Claude Code if you don't have it. In PowerShell run irm https://claude.ai/install.ps1 | iex, then run claude once and sign in with your Claude account.
  2. Download the helper (Windows). It's the same helper Screen Answers uses.
  3. Start it from PowerShell and leave the window open: powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\screen-answers-helper.ps1"

Notes count toward your plan's usage limits. Some browsers, especially school or work ones, block websites from reaching your PC. If so, open Class Notes from the helper at http://localhost:8787/class-notes/.

Get a key at console.anthropic.com. API use is billed separately from a Claude subscription. The key is saved only in this browser and sent only to api.anthropic.com.
