Handy tools that run in your browser. Open one to use it in this tab, or download it as a desktop app.

Screen Translator

Translation19 languagesDesktop

Share a screen, window or tab and it reads every word, then paints the translation right over the original. See up to four languages at once.

  • Live mode re-translates whenever the screen changes
  • Drag to translate just one area, like subtitles or a game menu
  • Float window keeps translations on top of your other apps
  • Translates on your device in Chrome, so the text stays private
  • Download it to get its own window and desktop icon, and open it offline
Open app Download Free. Installs as a desktop app in Chrome or Edge.

Screen Answers

Claude AIQuestionsLive

Share a screen, window or tab and Claude finds the questions on it and answers them, with a short explanation or full working if you want it.

  • Live mode answers again whenever the screen changes
  • Drag to ask about just one question, or paste a screenshot
  • Type follow-up questions about what's on screen
  • Uses your own Anthropic API key, saved only in your browser
Open app Free app. Needs an Anthropic API key; answers are billed to it.

Class Notes

Claude AISpeech to textSchool

Leave it listening during class. It writes down what the teacher says, and every few minutes Claude turns it into clean, organized notes.

  • Live transcript with times, in 15 languages
  • Tap ★ Important when something will be on the test
  • Pulls out homework, due dates and things to ask about
  • Outline, Cornell or short-summary notes; saves every class and downloads as Markdown
Open app Free. Works best in Chrome or Edge. Notes use your Claude plan or an API key.
